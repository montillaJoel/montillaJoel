Estudio en el **Instituto Tecnológico de las Américas (ITLA)**. **Python es mi lenguaje principal y FastAPI, mi framework principal para desarrollar APIs**. Mis primeros proyectos fueron programas pequeños que podía probar desde la terminal: una calculadora, una alarma y un juego de adivinanzas. En mi agente de investigación uso esa misma interfaz para algo distinto: escribir una pregunta y recibir un resumen con fuentes.

También desarrollo para el navegador con **HTML, CSS y JavaScript**. En escritorio, construí una aplicación con **Java Swing y MySQL** para gestionar cuentas de usuario. Además de las tecnologías que aparecen en esos proyectos, trabajo con **C++, PostgreSQL y Supabase**.

## Proyectos destacados

### 🔎 [Agente de investigación](https://github.com/montillaJoel/agente#readme)

**Python · Gemini · LangChain**  
El programa recibe una pregunta en la terminal. Gemini decide si necesita una consulta a Wikipedia o una búsqueda web con DuckDuckGo. Uso Pydantic para organizar la respuesta en cuatro campos: tema, resumen, fuentes y herramientas utilizadas.

¿Qué relación tuvo Ada Lovelace con la máquina analítica? Esta pregunta sirve de ejemplo para mostrar cómo el agente puede consultar Wikipedia o DuckDuckGo y devolver un resumen con fuentes. [Ver la consulta y su respuesta ilustrativa →](https://github.com/montillaJoel/agente#una-consulta-de-principio-a-fin)

### 🐍 [Seis programas de consola](https://github.com/montillaJoel/python-beginner-projects-by-Joel-David#readme)

**Python · Biblioteca estándar**  
En esta colección practico cómo validar entradas, trabajar con listas y controlar bucles. En el juego de adivinanzas, por ejemplo, cada intento recibe una pista para ajustar el siguiente número. En el conversor, introducir `25` grados Celsius devuelve `77.0` grados Fahrenheit.

Juega a adivinar un número, organiza tus tareas o prueba la calculadora, el conversor de temperatura, el generador de contraseñas y la alarma. [Elegir un programa y ejecutarlo →](https://github.com/montillaJoel/python-beginner-projects-by-Joel-David#cómo-ejecutarlos)

### 🖥️ [loginUsers](https://github.com/montillaJoel/loginUsers#readme)

**Java Swing · MySQL**  
Una persona puede registrar su cuenta, iniciar sesión y abrir el panel **Clientes Registrados**. Desde la tabla puede ordenar los registros, abrir una ficha con doble clic y ver los cambios al guardarlos.

Separé la interfaz, las validaciones y las consultas a MySQL en capas. Por ejemplo, al editar un correo, la ventana recoge el cambio y el servicio comprueba que sea válido antes de enviarlo a la base de datos. [Ver el panel de usuarios →](https://github.com/montillaJoel/loginUsers/blob/main/docs/panel-usuarios.png)
